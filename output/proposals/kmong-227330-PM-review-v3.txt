1. 종합 판정과 반영 우선순위

Designer 반영 우선순위
1) M1: 첫 페이지를 ‘대상·용도·핵심 조건·확인 근거’를 함께 읽을 수 있는 제안 요약으로 보강
2) M2: 맞춤 샘플 설명을 내부 점검 이력보다 발주자가 직접 확인할 세 가지 표현에 맞춤
3) M3: 계약 전 대표 모델 확인과 착수 후 전체 검수를 구분하고, 기존 검토일마다 발주처가 확인할 내용을 명시
4) M4: 마지막 35초를 영업·고객 설명에 사용할 핵심 포인트 정리까지 구체화
5) O1: 포트폴리오 영상의 추천 확인 구간 표시는 선택 개선. 현재 영상 카드와 과업 연결 문장은 이미 적절함

새 금액·수정 횟수·추가 승인 단계·추가 산출물은 제안하지 않는다. 700만원 VAT 포함과 콘티 1회·본편 1회 수정은 사용자 검토용 제안 초안이라는 상태를 유지한다. 실제 고객 모델은 미확인 상태다.

3. 주요 개선 4개와 선택 개선 1개

[M1 / 우선 반영] 첫 페이지에서 ‘왜 이 제안인가’와 비교 조건을 함께 보여주기

위치:
PDF 1페이지의 부제·우측 설명·핵심 조건, 제출 본문의 첫 제안 문단과 [제안 금액과 모델 범위].

문제:
현재 화면 구성 방식은 잘 설명되어 있지만 공고의 ‘현장 관계자·클라이언트 이해’와 ‘영업/마케팅 활용’이 첫 페이지에 직접 드러나지 않는다. 금액은 7페이지에 있고 원본 제공 가능 여부도 ‘편집 원본’이라는 단어로만 보인다. 발주자가 다른 제안과 빠르게 비교할 때 핵심 조건을 모아 읽기 어렵다.
이는 내용 누락이나 필수요건 위반이 아니라 판단 편의와 메시지 선명도의 개선이다.

실제 영향:
발주자가 ‘조립 과정을 보여준다’는 일반 설명을 넘어 누구에게 무엇을 설명하는 영상인지, 제안 금액·납품·원본 조건이 무엇인지 첫 장에서 판단할 수 있다. 이미 만들어 둔 맞춤 샘플이 구체적인 선택 근거로 작동한다.

교체·추가 문장안:
부제: “현장 관계자는 부재 관계와 조립 순서를, 잠재 고객은 전체 구조가 구성되는 흐름을 이해할 수 있는 설명 영상을 제안합니다.”
선택 근거 한 줄: “이번 과업을 위해 제작한 30초 샘플로 화면 구성과 설명 방식을 먼저 확인하실 수 있습니다.”
빠른 비교 요약: “3~4분 · 한국어 자막 · 4K/1080p · 11.30 납품 · 편집 원본 제공 가능”
금액 보조 표시: “제안 초안 700만원 · VAT 포함 / 제공 모델 활용 기준”

Designer 실행지시:
- 현재 대표 샘플 이미지를 유지한다. 우측의 일부 반복 문장을 줄여 대상·용도 설명과 금액 보조 표시를 배치한다.
- 700만원은 반드시 ‘제안 초안’으로 표시하고 상세 범위는 7페이지에서 확인하도록 연결한다. 이를 확정 계약금액으로 만들지 않는다.
- 숫자와 약속을 작은 각주 하나에 몰아넣지 않는다. 새로운 슬로건보다 실제 조건과 샘플 근거가 먼저 읽히게 한다.
- 제출 본문의 첫 문단에도 현장 관계자·잠재 고객의 이해와 영업 설명 활용 목적을 같은 의미로 반영한다.

[M2 / 우선 반영] 샘플을 평가하는 관점을 발주자에게 제시하기

위치:
PDF 2페이지 하단 ‘샘플에서 점검한 표현’, 제출 본문의 [맞춤 샘플과 관련 3D 작업] 첫 문단.

문제:
접점·부속품 동반 이동·임시 지지 유지 등 점검한 항목은 사실이고 유효하다. 다만 제작 과정에서 어떤 오류를 확인했는지를 먼저 설명하는 구조여서, 발주자가 30초 영상에서 어떤 제작 역량을 평가하면 되는지 즉시 정리되지는 않는다.

실제 영향:
샘플의 역할을 ‘검수 이력’에서 ‘본편을 맡겼을 때 기대할 화면과 설명 방식’으로 전환할 수 있다. 과업 맞춤 샘플의 설득력을 올리면서 새 장면이나 영상 재제작을 요구하지 않는다.

교체 문장안:
소제목: “샘플에서 확인하실 세 가지”
① “기둥·보·슬래브가 놓이는 순서”
② “전체 구도와 받침부 근접 시점의 연결”
③ “공정명·안착 관계·생략 단계를 알리는 자막과 강조 표현”
품질 점검 보조 한 줄: “임시 지지와 받침부 등 장면 간 표현의 일관성을 점검했습니다.”
본문 예시: “30초 맞춤 샘플에서 배치 순서, 전체와 상세 시점의 전환, 자막·강조 표현을 확인하실 수 있습니다. 본편은 실제 모델과 발주처가 확인한 접합 상세·공정 설명으로 확장합니다.”

Designer 실행지시:
- 위 세 항목을 기존 세 스틸 또는 하단 정보 패널에 대응시킨다. 실제 영상에 없는 분해 조립·접합 완료 장면을 새로 그려 증거처럼 넣지 않는다.
- ‘실제 모델과 승인 자료로 확장’ 패널은 유지하고 내용만 중복 없이 짧게 정리한다.
- 샘플이 일반화한 배치 개념이며 구조 검토·시공 절차 승인용이 아니라는 현재 경계 표시는 한 번 명확히 유지한다. 경계를 없애거나 큰 경고 패널로 늘리지 않는다.
- 내부 점검 항목 전부를 첫 설명 문단에 반복할 필요는 없다. 제출 본문도 발주자가 확인할 표현 → 실제 자료로 확장 순서로 맞춘다.

[M3 / 우선 반영] 자료 확인의 시점과 검토일의 판단 내용을 구체화하기

위치:
PDF 6페이지 일정·의견 취합 설명, 7페이지 ‘대표 모델 검수 후 확정’, 제출 본문의 [일정과 검토]·[제안 금액과 모델 범위].

문제:
7페이지에서는 계약 전에 대표 모델을 확인해 범위·금액을 정한다고 하고, 6페이지에서는 11.10~12 착수 후 모델 검수를 제시한다. 서로 모순이라고 단정할 수는 없지만 두 확인의 범위와 시점이 구분되지 않는다.
또한 11.16·11.22·11.25 검토일은 명확한데, 발주처가 각 시점에 무엇을 확인해야 하는지는 ‘콘티·초안·내용 확정’이라는 단계명에 머문다. 기술 정보의 확인과 영상 표현의 승인이 섞여 보일 수 있다.

실제 영향:
발주자가 견적 판단에 어떤 자료가 필요한지, 착수 뒤 어떤 의견을 준비해야 하는지 이해할 수 있다. 기존 일정과 승인 횟수 안에서 재확인을 줄일 수 있다. 책임을 발주처로 넘기는 문장보다 협업 방식으로 읽히게 된다.

교체 문장안:
시점 구분: “계약 전에는 대표 모델로 불러오기와 가공 필요 범위를 확인해 견적 범위를 정합니다. 착수 후에는 전체 모델·공정 자료를 검수하고 대표 장면의 4K 시험 렌더를 진행합니다.”
자료 확인 요약: “확인할 자료: 제공 모델의 형식·단위·부재 분리 상태, 조립 순서와 접합 참고 자료, 부재 명칭과 주요 설명 문구.”
기존 검토일에 붙일 확인 내용:
- 11.16 콘티·동작안: “설명 범위·공정 순서·전체/상세 시점 확인”
- 11.22 본편 초안: “부재·접합 표현과 명칭·자막 확인”
- 11.25 내용 확정: “수정 반영과 최종 설명 문구 확인”

Designer 실행지시:
- 계약 전 대표 모델 확인은 7페이지의 기존 범위 협의에 붙인다. 별도의 신규 승인 단계나 추가 회신 기한을 만들지 않는다.
- 6페이지 우측의 추상적인 의견 취합 문장 일부를 위 세 ‘확인 내용’으로 대체한다. 납품 QA 목록·11.29 예비일·지연 영향 공유 문장은 유지한다.
- 모델·공정 자료 목록은 간단히 표시한다. 새로운 인증서·구조계산서·법적 서류를 필수 제출자료로 요구하지 않는다.
- 공정 표현의 근거는 발주처가 확인한 자료라는 의미를 유지한다. ‘승인’이라는 말이 건축 인허가나 외부 전문기관의 공식 검증을 받은 것처럼 읽히게 만들지 않는다. 변경관리의 기준인 ‘승인된 콘티’는 유지한다.
- PDF와 본문 모두 계약 전 대표 모델 확인 / 착수 후 전체 검수의 시점 구분을 동일하게 반영한다. 실제 고객 모델을 이미 검증한 것처럼 쓰지 않는다.

[M4 / 권장 반영] 영업 설명에 사용할 마지막 구간의 역할을 명시하기

위치:
PDF 5페이지 02:55~03:30 ‘최종 상태와 핵심 정리’, PDF 1페이지의 활용 목적, 제출 본문의 첫 문단.

문제:
현재 구성안은 조립 순서 설명에 충실하다. 그러나 공고의 또 다른 목적은 영업·마케팅 자료 활용이다. 마지막 35초는 ‘전체 상태와 주요 공정 요약’ 정도로만 적혀 있어, 잠재 고객에게 무엇을 남길지 판단하기 어렵다.

실제 영향:
3분30초 영상이 현장 관계자용 순서 설명과 고객 제안·발표용 요약을 함께 지원한다는 점을 보여준다. 공고 목적에 맞는 구성 선택을 구체적으로 설명할 수 있다.

교체 문장안:
마지막 행의 설명 주제: “최종 상태와 고객 설명용 핵심 정리”
마지막 행의 시청자 이해 내용: “전체 구조와 조립 흐름을 회수하고, 발주처가 확인한 주요 설명 포인트를 정리”
페이지 보조 문장: “마지막 구간은 고객 제안·프레젠테이션에서 설명할 핵심 포인트를 정리하는 데 활용합니다.”

Designer 실행지시:
- 기존 02:55~03:30의 35초 안에서 역할을 구체화한다. 총 210초와 기존 6단계는 유지한다.
- 주요 포인트는 부재의 역할·조립 순서·접합 관계 등 확인 가능한 설명 내용으로 구성한다. 공기 단축·공사비 절감·내구성·안전성 우수 같은 미제공 성능을 만들어 넣지 않는다.
- 새 홍보 영상·세로 SNS 영상·추가 납품물을 약속하지 않는다. ‘발주처가 확인한 특징’이라는 표현은 실제 자료로 확인된 범위에서만 사용한다.
- 이 변경은 필수요건 누락의 수정이 아니라 발주 목적을 더 잘 드러내는 구성 보강이다.

[O1 / 선택 개선] 영상 카드에 확인 구간을 짧게 표시하기

위치:
PDF 3·4페이지 영상 카드, 제출 본문의 두 영상 소개.

현재 판단:
실내 시네마틱과 기계형 오브젝트를 과업에 연결하는 설명은 이미 적절하다. 포트폴리오 순서·대표 프레임·세로 비율·공개 영상과 현재 상세 화면의 구분을 전면 수정할 이유는 없다.

선택 개선과 실제 영향:
바쁜 평가자가 관련 구간을 바로 볼 수 있도록 확인 포인트 한 줄을 붙일 수 있다. 전체 영상을 끝까지 봐야만 관련성을 이해하는 부담을 줄이고 그래픽 비교나 게임 위시리스트 안내보다 과업 관련 화면에 집중하도록 돕는다.

추가 문장안:

4. 견적·수정·납기의 표현에 대한 판단

현재 v2의 700만원 VAT 포함, 콘티 1회·본편 1회, 제작 오류 차감 제외, 고정 납기, 권한 범위 내 원본 인계는 서로 일관되어 있다. 새 금액·새 수정 횟수·무조건적인 모델 변환 보증을 더할 이유는 없다.
대표 모델을 보고 계약 전에 범위를 정한다는 조건도 실제 모델 미확인 상태에서는 타당하다. M3는 이 조건을 강화해 일을 막으려는 것이 아니라 같은 ‘검수’라는 말이 가리키는 계약 전후 작업을 구분하려는 권고다.
‘생략 공정’이나 ‘구조 검토 제외’ 표시는 샘플의 성격을 정확히 설명하는 필요 정보다. 불필요한 방어 문구라는 이유로 삭제하지 않는다. 단, 같은 경계를 각 페이지마다 반복해 제안 메시지를 가리지 않게 한다.

5. PDF와 제출 본문의 일관성 지시

v2에서 기존 금액·일정·납품물·수정·영상 링크의 실질적 불일치는 발견하지 못했다. v3는 아래 변경을 함께 반영한다.
- M1의 대상·활용 목적은 첫 제안 문단에 반영
- M2의 샘플 확인 포인트는 [맞춤 샘플과 관련 3D 작업]에서 동일한 세 가지로 표현
- M3의 계약 전후 확인 시점은 [일정과 검토]·[제안 금액과 모델 범위]에 같은 의미로 반영
- M4는 3분30초 구성안의 마무리 역할로만 설명하고 별도 산출물로 쓰지 않음
- O1을 PDF에 넣는 경우 본문에도 선택적으로 한 줄 추가 가능하나, 두 영상 URL과 길이는 그대로 유지

6. Designer 페이지별 실행 요약

1페이지:
대상·용도와 30초 맞춤 샘플이라는 근거를 앞세운다. 700만원 VAT 포함 ‘제안 초안’ 및 ‘편집 원본 제공 가능’을 첫 장에서 찾아볼 수 있게 요약한다. 이미지·고정 납품일·기존 납품 조건은 유지한다.

2페이지:
하단 좌측 패널을 ‘샘플에서 확인하실 세 가지’로 전환한다. 배치 순서 / 전체-근접 시점 / 자막·강조 표현을 실제 스틸과 대응시킨다. 실제 자료로 확장하는 설명과 개념 샘플의 한계는 짧고 분명하게 유지한다.

3페이지:
기존 시네마틱·욕실 포스터와 클릭 링크·QR, 과업 적용 문장은 유지한다. 추천 확인 구간 표시는 공간이 충분한 경우의 선택 개선이다.

4페이지:
9:16 공개 시네마틱과 현재 개발 상세 화면을 구분하는 기존 구조를 유지한다. 소품 사례는 보조로 둔다. 영상 추천 구간 표시는 선택 사항이며 실적·성능·출시 상태를 새로 주장하지 않는다.

5페이지:
기존 210초·6단계를 유지한다. 마지막 35초의 설명을 고객 제안·프레젠테이션에서 핵심을 정리하는 용도까지 구체화한다. 근거 없는 공법 성능·비용 효과를 추가하지 않는다.

6페이지:
11.10 이후의 검수를 전체 모델·공정·자산 검수로 명료화한다. 11.16·11.22·11.25의 기존 검토일 옆에 확인 포인트를 붙인다. 자료 목록은 짧게, 추가 승인 흐름 없이 제시한다. 기존 QA와 지연 대응은 유지한다.

7페이지:
대표 모델 확인은 계약 전 견적 범위 확인임을 명료화한다. 기존 기본 포함·별도 확정·수정/변경·원본/권한·세금계산서 구분을 유지한다. 글자를 줄이기 위해 계약 조건이나 자산 인계 한계를 삭제하지 않는다.
