1. 프로젝트 이해와 접근
이번 과업은 PC 관리자 웹의 PHP 기반 프론트엔드를 JavaScript 생태계로 전환하고, 기존 API를 활용해 UI/UX를 개선하는 프로젝트로 이해했습니다. 메뉴 구조와 업무 규칙은 유지하며, 로그인·권한별 대시보드·통계/리포트·알림/공지·사용자/권한 관리·파일 업로드/다운로드·결재/승인을 빠짐없이 대조하겠습니다. 사용자·권한 관리의 고도화 범위는 협의해 확정합니다.

먼저 미팅에서 화면 목록과 필수 업무를 정리하고, 계약 후 제공되는 소스·API 명세와 대조하겠습니다. 대표 화면을 먼저 구현해 방향을 확인한 뒤 공통 컴포넌트를 적용합니다. 고객님은 개발 초기에 실제 화면과 동작을 확인하실 수 있습니다.

2. 기술 제안과 품질 확인
React + TypeScript + Vite + Material UI를 제안합니다. TypeScript로 데이터와 컴포넌트의 연결 오류를 줄이고, 표·검색·필터·입력폼·오류 안내의 사용 방식을 통일하겠습니다. Node.js는 개발·빌드 도구로 활용하며, 신규 백엔드 구축은 제안 범위에 포함하지 않습니다.

기존 인증 방식과 API 계약을 유지합니다. 권한별 화면뿐 아니라 API 접근 결과도 확인하고, API 미제공 기능이나 PHP 내부의 업무 로직이 확인되면 처리 방안과 일정 영향을 공유해 사전 합의하겠습니다. 통계 수치·파일 처리·결재 상태는 기존 결과와 대조합니다.

MySQL -> MariaDB 소량 데이터 이전은 버전·문자셋·쿼리 호환성 점검, 백업, 시험 이전, 건수·핵심 값·API 동작 대조 후 진행합니다. 운영 전환은 쓰기 중지 구간과 복귀 절차를 합의하고, 검증과 승인 후 수행하겠습니다.
